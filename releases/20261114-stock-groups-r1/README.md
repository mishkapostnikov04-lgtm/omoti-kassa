# «Остатки» по разделам и просмотр остатков Аникиной, r1 · 14 ноября 2026

Решение владельца 14.11.2026. Копии `20261114-transfer-kind-r1` (байты Git) с правками.

Новогодняя и Советская (`points-interface.js`): список пересчёта во вкладке «Остатки» разбит на разделы «Моти» / «Кейки» /
«Мункейки», как блоки экрана продажи. Раздел — `cashierBlock` позиции (только у позиций отдельных блоков), без блока — «Моти»;
«Моти» первым, затем блоки по `order`; внутри — прежний алфавит; пустой раздел не показывается. Заголовки разделов строит
встроенный код HTML (`restockGroupedCards`, прежний серый заголовок списка с числом вкусов); слой убирает общий заголовок «Моти»
и даёт отступ 8 px перед вторым и третьим разделом. Ввод 0–5 / 6+ / точное число, расходники, отправка, очередь — прежние.

Аникина (`anikina-interface.js`): новая вкладка «Остатки» — ТОЛЬКО ПРОСМОТР, без полей ввода и без отправки. Встроенный код
читает `GET /b2c-api/point-restock/stock?locationId=anikina` (токен устройства кассы) при каждом открытии вкладки и по кнопке
«Обновить»; число — `qty` сервера (centralQty ?? effectiveStock, как «Пульс»), отрицательное показывается как 0, нет в ответе — «—».
Список — вкусы экрана продажи (без наборов), те же разделы. Вкладок пять (с «Оплатой» sbp-link): колонок столько, сколько
видимых кнопок, подпись под значком — как в четырёх вкладках точек.

Сервер: `cashier-stock-groups-20261114-r1` (GET stock для Аникиной). До его выкладки вкладка Аникиной показывает
«Не удалось загрузить остатки»; продажа и остальные вкладки работают. Кассы точек от сервера не зависят.
QA: `_qa/stock-groups/stock-groups.cjs` (перехваченный транспорт, service worker заблокирован).
