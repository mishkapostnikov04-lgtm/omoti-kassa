# Блоки «Кейки» и «Мункейки» в кассах, r1 · 14 ноября 2026

Решение владельца 14.11.2026. Копии `20261110-dock-sum-r2`; изменены `renderFlavors` и `reconcileTiles`.
Отдельный блок после моти делится по полю сервера розницы `cashierBlock` (`{id, name, order}` — группа товара):
сначала позиции без названного блока, затем блоки по `order` («Кейки» 20, «Мункейки» 30). Каждый блок — с новой
строки, плитки прежние (белые, тонкая рамка). Наборы — в конце, как раньше.

Константа `BLOCK_CAPTIONS` в обоих файлах: `true` — над блоком маленькая серая подпись группы (18 px,
`--k-fs-group`, `--k-muted-2`); `false` — без подписей, только новые строки. В выпуске — `true`.

Без поля `cashierBlock` (сервер до `cashier-group-blocks-20261114`) сетка ровно как раньше: один блок без заголовков.
Продажа, цены, акции, бонусы, PIN, очереди, service worker, хранилище и итоги не менялись.
