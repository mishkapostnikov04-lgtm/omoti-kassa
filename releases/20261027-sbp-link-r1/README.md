# sbp-link-20261027-r1 — Аникина, вкладка «Оплата»

Ссылка на оплату через СБП (торговый эквайринг Т-Банка, «QR-код на кассовом ПО»). Продавец вводит сумму,
сервер B2C (`/b2c-api/cashier-sbp/links|status`, backend `cashier-sbp-link-20261027-r1`) создаёт динамический QR
и возвращает ссылку; ключ банка только на сервере. Чеки 54-ФЗ не формируются (решение владельца).

- `sbp-link.js` / `sbp-link.css` — изолированный модуль `#screen-pay`; не входит в обязательные boot-ресурсы:
  при сбое загрузки вкладка скрыта, касса работает.
- `qrcode-generator-1.4.4.min.js` — MIT, SRI сверен с cdnjs.
- В `omoti_anikina.html`: 4-я кнопка `#tab-pay` (hidden до загрузки модуля), `#screen-pay`, RELEASE, ресурсы с SRI.
- Новогодняя/Советская не менялись.
