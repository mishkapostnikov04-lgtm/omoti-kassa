# Акция: скидка или бонусы, r3 · 10 ноября 2026

Копия r2. При смене способа оплаты на экране остаётся прежний подтверждённый расчёт, пока касса заново
спрашивает сервер (цены для оплат с картой одинаковые) — сумма в доке больше не моргает. Закрыть чек —
только после нового подтверждённого ответа. `dockSummary()` отдаёт доку подтверждённые списание и скидку.
