# Акция: скидка или бонусы · 10 ноября 2026

Решение владельца 10.11.2026: в одном чеке с картой — либо скидка по акции, либо списание бонусов.
Решение принимает сервер розницы (`promo-or-bonus-20261110-r1`): при списании > 0 чек считается
по полной цене, скидка снимается; при списании 0 скидка действует. Касса показывает ответ сервера.

Изменено только в `loyalty.js` (копия `20261022-standard-edit-r1/loyalty.js`):
- предел списания и «Максимум» при акции — 30% полной суммы чека (`redeemBasisTotalMinor`);
- подпись предела «Не больше 30% суммы чека.»;
- одна строка-подсказка в листе карты: сколько даёт скидка и сколько можно списать, или что скидка не применена.

Без новых полей в ответе сервера поведение прежнее. В HTML трёх касс — только адрес и SRI скрипта.
Продажа без карты, цены, оплаты, PIN, очереди, service worker и хранилище не менялись.
