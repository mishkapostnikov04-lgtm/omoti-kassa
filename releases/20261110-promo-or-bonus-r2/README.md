# Акция: скидка или бонусы, r2 · 10 ноября 2026

Замечание владельца при проверке: до выбора оплаты касса показывала свой подсчёт (скидка и списание вместе),
продавец мог назвать клиенту неверную сумму. Копия `20261110-promo-or-bonus-r1/loyalty.js`:
- карта выбрана, оплата ещё нет — касса сразу спрашивает сервер (как для «Безналичный», цены для оплат с картой одинаковые);
- при действующей акции до подтверждённого ответа сервера «К оплате» и «Можно списать» — прочерк.
Закрыть чек по-прежнему можно только после выбора оплаты и подтверждённого расчёта. В HTML — только адрес и SRI.
