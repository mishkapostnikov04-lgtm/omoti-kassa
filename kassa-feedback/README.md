# OMOTI cashier feedback · r1

## Текущий r2 · исправление проверки iPhone

Активный модуль — `v2/feedback.js`, адаптер `releases/20261021-feedback-r2/anikina-interface.js`. R1 ниже и корневой feedback.js сохранены для старых документов/кэшей. Отсутствие/отказ экспериментального audioSession больше не блокирует обычный Web Audio; ambient запрашивается при наличии API, playback/HTML audio/mute bypass не применяются. Контекст resume и нулевой Web Audio frame отправляются в самом жесте. Только явная команда `test()` может ждать decode (с ограничением времени); обычные сигналы по-прежнему не ставятся в очередь. `test()` теперь возвращает Promise с результатом запуска, `status()` — неперсональные диагностические признаки в памяти. Новый ключ хранилища не добавлялся. Кнопка показывает подготовку и результат/ошибку. Cache r2 содержит v2/feedback.js с?v=20261021-r2 и прежние9MP3 с?v=20261021-r1. Две соседние кассы не подключены; реальный iPhone и его haptic остаются ручной проверкой.

Дополнительная регрессия: `_qa/feedback/ios-regression.cjs` (отсутствует/отказывает audioSession, первый тест с задержанными MP3, сетевой отказ/повтор, выключение во время проверки, suspend/resume). `_qa/feedback/webkit-probe.cjs` показывает возможности настоящего Windows WebKit, который в этом комплекте не предоставляет AudioContext: это **не** доказательство звука на физическом Safari/iPhone. Текущий отчёт — `_local_artifacts/kassa-feedback-20261021/iphone-fix/REPORT.md` в родительском проекте.

## История r1 (заменён r2)

Один необязательный модуль, сейчас подключён **только в Аникиной** по уточнению владельца21.10.2026. Утверждённый пакет `omoti-kassa-feedback-20261021.zip`, файлы01–09 скопированы побайтно;10/WAV/генератор не входят в runtime. Новогодняя/Советская не подключены.

API: `init({point})`, `signal(name,{fromTouch})`, `settings()`, `setSettings({sound,vibration})`, `test()`. Только одна новая запись `omoti_<point>_feedback_v1`. Исключения поглощаются, на пути действия нет await. Загружаются9MP3, decode после первого trusted gesture; пропущенные результаты не проигрываются задним числом.

Web Audio gain0.7; audioSession ambient. На iOS без поддержки ambient звук консервативно отключён, без принудительного playback/unmute. Нет доступа к состоянию аппаратного беззвучного переключателя и нет обещания автоматической вибрации для асинхронного результата на iPhone. Вибрация iPhone — только синхронная активация скрытого switch-label в обработчике; реальная поддержка зависит от версии Safari/устройства. Программный label скрыт от фокуса/скринридера; видимые настройки — обычные подписанные checkbox, чтобы сами переключения не создавали дополнительную системную вибрацию.

Приоритет: error8 > needInput7 > sale/savedOffline/service6 > restockSent/notice5 > cardFound4 > queueSent3 > tap2. Интервал одного имени400ms, tap60ms; низкий сигнал пропускается во время высокого, равный/высокий заменяет текущий. Фон останавливает и подавляет отклик. Reduced motion не влияет. `test()` уважает обе настройки.

Интеграция: `releases/20261021-feedback-r1/anikina-interface.js`. Модуль не читает бизнес-данные. UI-адаптер наблюдает существующие DOM/очередь/тосты, подтверждает сохранение тем же условием, что flash C3.2. Сбой загрузки feedback не входит в обязательный boot handshake; интерфейс работает без звука. Все обязательные ресурсы/guard сохраняются.

Worker Аникиной кеширует только точный allowlist feedback.js и9MP3 с?v=20261021-r1; network-only HTML, существующие push handlers/cache/LS/очереди не меняются. Регистрация worker при открытии меню не требуется: UI регистрирует его без запроса разрешения на push. Естественная активация, без skipWaiting/clients.claim/reload/удаления cache. Для первого кеширования нужен успешный сетевой доступ; offline холодный запуск приложения по-прежнему безопасно блокируется текущим startup supervisor.

Проверки: `_qa/feedback/README.md`. Телефонная приёмка и полная матрица — `_local_artifacts/kassa-feedback-20261021/REPORT.md` в родительском проекте. Первичные технические источники: [W3C audio-session](https://www.w3.org/TR/audio-session/), [WebKit switch feedback](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/). Наличие API/вызов label в эмуляции не доказывает физический haptic или соблюдение mute на устройстве.
